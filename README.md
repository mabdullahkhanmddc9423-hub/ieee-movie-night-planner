
# Movie Night Planner

## 1. Project Overview
This project is a movie recommendation and watchlist manager. It dynamically reads a library of movies from an external file, allows users to browse and filter by genre or rating, and curates a personalized watchlist with automated analytics.
## 2. Concepts Implemented
* Object-Oriented Programming (Classes, Objects, Encapsulation)
* File Handling (Reading external data dynamically)
* Error & Exception Handling (try/except blocks for file reading and user inputs)
* Data Structures (Lists, Sets for preventing duplicate watchlist entries)
* List Comprehensions (Filtering movies rapidly)
## 3. How to Run the Program
python main.py

## 4. Dataset Information
The dataset movies.csv contains 10 structured rows featuring a mix of movie titles, genres, float ratings, and integer durations.
